## About

- I build UI and API automation in **Java** — Selenide, REST Assured, JUnit 5 / TestNG — and wire it into pipelines so a red run actually blocks a merge, instead of decorating a dashboard.
- Beyond tests I ship product code: a real-time 3D web client on **Babylon.js / WebGPU**, a **Kotlin + Spring Boot** service behind it, and the CI that keeps both honest.
- I work **agent-first** — custom agent skills, hooks and subagent pipelines around LLM-assisted development, with cost and observability harnesses so the loop stays measurable.
- Most of that lives in private repositories; what is public here is the test-automation and side-project half.
